## 9. Target Performance Metrics

| Metric | Target | Measurement Method |
|--------|-------|-------------------|
| **Frame Rate** | 60 FPS (high-end), 30 FPS (low-end) | Unity Profiler, Device logs |
| **Initial Load Time** | < 10 seconds on 4G | Client-side timing |
| **Asset Download** | < 50MB initial bundle | Network monitoring |
| **API Response (p95)** | < 200ms | Application performance monitoring |
| **Recommendation Latency** | < 300ms from request to display | End-to-end timing |
| **Position Update Latency** | < 100ms peer-to-peer | Network timing |
| **Memory Usage** | < 800MB (iOS), < 600MB (Android) | Xcode Instruments, Android Profiler |
| **Battery Impact** | < 15% per hour on modern devices | Device battery monitoring |
| **Concurrent Users per Region** | 5,000 active avatars | Load testing |
| **Database Query Time** | < 50ms for 95% of queries | Database monitoring |

## 9. Target Performance Metrics

### Notes on Key Relationships

**Concurrent users per region and avatar awareness limit are directly coupled.**
The 5,000 concurrent avatar target per region is only achievable because each client
receives position updates for a maximum of 50 avatars — those within its interest
management radius. If the awareness limit is raised, the broadcast volume per region
server increases proportionally and the concurrent user ceiling drops. These two
numbers must always be tuned together.

**Frame rate targets are tier-dependent.**
The 60 FPS target applies to high-tier devices only. Mid-tier targets 30 FPS and
low-tier targets 24 FPS. The metrics below represent the full range.

**Nigerian network conditions are the baseline, not an edge case.**
All latency and download targets are set against 4G conditions in Abuja, not
high-speed broadband. Meeting these targets on good WiFi is not sufficient.

### Performance Targets

| Metric | Target | Device / Condition | Measurement Method |
|--------|--------|-------------------|-------------------|
| **Frame Rate — High Tier** | 60 FPS sustained | iPhone 12+, Samsung S21+ | Unity Profiler, Xcode GPU |
| **Frame Rate — Mid Tier** | 30 FPS sustained | Samsung A54, Tecno Camon 20 | Unity Profiler, Android GPU Inspector |
| **Frame Rate — Low Tier** | 24 FPS sustained | Tecno Spark, Infinix Hot series | Unity Profiler, device logs |
| **Initial Load Time** | < 10 seconds | 4G Abuja conditions | Client-side timing |
| **Asset Download (Initial)** | < 50MB | First install, any network | Network monitoring |
| **API Response (p95)** | < 200ms | From af-south-1 to Abuja | Application performance monitoring |
| **Recommendation Latency** | < 300ms end-to-end | Request to pins rendered on map | Client-side end-to-end timing |
| **Position Update Latency** | < 100ms | Client A to Client B via SignalR | Network timing, SignalR diagnostics |
| **Memory — High Tier** | < 800MB | iPhone 12+, flagships | Xcode Instruments, Android Profiler |
| **Memory — Mid Tier** | < 500MB | Mid-range Android | Android Profiler |
| **Memory — Low Tier** | < 300MB | Budget Android | Android Profiler |
| **Battery Impact** | < 15% per hour | High-tier on 4G, screen on | Device battery monitoring |
| **Battery Impact — Low Tier** | < 20% per hour | Budget Android, data saver on | Device battery monitoring |
| **Concurrent Users per Region** | 5,000 active avatars | Per SignalR region group | Load testing with k6 or Gatling |
| **Avatar Awareness Limit** | 50 avatars per client | Directly coupled to CCU target above | Client-side monitoring |
| **Database Query Time** | < 50ms for 95% of queries | PostgreSQL with PostGIS indexes | pg_stat_statements, slow query log |
| **SignalR Reconnection Time** | < 3 seconds | On network handoff (WiFi → 4G) | Client-side timing |
| **Data Saver Mode Bandwidth** | < 5MB per hour of active use | Low-tier devices, 5Hz update rate | Network monitoring |

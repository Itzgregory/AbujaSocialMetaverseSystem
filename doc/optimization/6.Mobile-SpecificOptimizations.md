## 6. Mobile-Specific Optimizations

| Factor | Consideration | Optimization Strategy |
|--------|---------------|----------------------|
| **Battery Consumption** | Continuous 3D rendering and network activity drains battery. | • Reduce frame rate when user is idle (60Hz → 30Hz)<br>• Implement network coalescing—batch updates<br>• Reduce rendering resolution on battery saver mode<br>• Use lower LOD levels when device temperature rises |
| **Thermal Throttling** | Prolonged use causes device to throttle performance. | • Monitor device temperature and degrade quality automatically<br>• Implement adaptive quality based on frame rate targets<br>• Reduce max visible avatars when thermal limits approached<br>• Limit session duration for intensive activities |
| **Memory Pressure** | iOS and Android aggressively terminate apps using too much memory. | • Set maximum memory budgets (iOS: 1.5GB, Android: varies by device)<br>• Implement memory pressure callbacks to release caches<br>• Use memory pools instead of per-frame allocations<br>• Load streaming assets on demand instead of all at once |
